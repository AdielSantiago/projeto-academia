# 🏋️‍♂️ Aplicação Web de Saúde e Exercícios Físicos

> Projeto acadêmico desenvolvido para criar uma experiência web acessível e responsiva voltada à promoção da atividade física para diferentes faixas etárias.

---

## 📌 Sobre o Projeto

Aplicação web focada em saúde, bem-estar e inclusão física para jovens, adultos e idosos. O sistema oferece orientações de treinos adaptados e dicas de vida saudável através de uma interface leve, intuitiva e responsiva.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização, layout flexível e design responsivo.
* **JavaScript:** Interatividade da interface e manipulação do DOM.
